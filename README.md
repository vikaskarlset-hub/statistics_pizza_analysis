Pizza Sales Statistical Analysis

Statistical analysis of pizza sales data using Python to identify sales patterns, customer purchasing behaviour, and product performance.

Tools used: 
Python,
Pandas,
NumPy,
Matplotlib,
Seaborn,
Google Colab.

Analysis

The project includes:

Descriptive statistics: mean, median, mode,
Skewness and kurtosis analysis,
Variance, standard deviation, MAD, and range,
Distribution analysis and comparison with the normal distribution,
Outlier detection using boxplots and z-scores,
Sales analysis by month and day of the week,
Analysis of sales by pizza category and size,
Identification of top and bottom pizza products by revenue and sales volume,
Analysis of sales by time of day,
Average order value (AOV) analysis by day of the week.

Visualizations

The analysis includes histograms, boxplots, bar charts, and pie charts to visualise key patterns and findings in the data.
